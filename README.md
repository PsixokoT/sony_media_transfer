# sony_media_transfer

Приложение для Windows 11, которое копирует фото и видео с Sony A7 IV (прошивка 6.01) на компьютер.

## Спецификация

### Стек

- Tauri 2. Логика на Rust (`src-tauri/`), интерфейс на TypeScript + React + Vite (`src/`).
- Rust stable и Node 24 закреплены в `mise.toml`. MSVC Build Tools (C++ и Windows SDK) ставятся через winget.
- Результат сборки — portable exe, без установщика и автообновлений.
- Только Windows 11.

### Откуда берём файлы

- Камера работает в режиме MassStorage (MSC): `MENU → Setup → USB → USB Connection Mode → MassStorage(MSC)`, `USB LUN Setting` = Multi. MTP (показывает только слот 1 и работает медленно) и Camera Remote SDK не используем.
- Картой камеры считается съёмный диск, на котором есть `DCIM\NNNxxxxx`, `M4ROOT` (CFexpress Type A) или `PRIVATE\M4ROOT` (SD). Диск PMHOME (внутренняя память камеры, там папка LICENSE) и пустые слоты пропускаются. Картридер и флешка с такой же структурой распознаются так же.
- Подключение и отключение камеры отслеживаются автоматически: раз в 2 с приложение проверяет, какие съёмные диски — карты (только папки, файлы не читаются). Файлы перечитываются, только когда набор карт меняется.

### Файлы и группировка

- Фото: ARW на слоте 1, JPG или HEIF (`.HIF`) на слоте 2. Видео (XAVC S и XAVC HS): `M4ROOT\CLIP\C0001.MP4` + `C0001M01.XML`, прокси `M4ROOT\SUB\C0001S03.MP4`. На SD-карте перед `M4ROOT` есть ещё `PRIVATE\`. `MEDIAPRO.XML` — служебный файл, его не копируем.
- Файлы со всех карт показываются одним списком по дням. День — это дата съёмки: у фото EXIF `DateTimeOriginal`, у видео `CreationDate` из XML. Если метаданных нет, берётся дата файла. Граница дня — полночь.
- Новые сверху: дни идут от последнего к первому, внутри дня последний кадр слева вверху.
- Одна плитка — один кадр или клип. ARW, JPG и HIF связываются по имени и дате съёмки, MP4, XML и прокси — по номеру клипа. Если на двух картах лежат одинаковые файлы, копируется один.
- В подписи плитки перечислены расширения её файлов, а у клипа с прокси ещё «прокси»: «MP4 XML прокси».

### Просмотр и отбор

- Превью фото — JPEG, встроенный в ARW (у JPG — миниатюра 160×120 из EXIF). В полноэкранном просмотре JPG показывается целиком.
- У HIF превью — встроенные HEVC-картинки 1616×1080 и 320×212, их декодирует WebView2 через WebCodecs: в сетке 320×212, в просмотре самая большая из тех, что декодируются. HEVC 4:2:2 декодируется не на всякой видеокарте, тогда в просмотре 320×212 (она всегда 4:2:0). Если HEVC не декодируется вовсе, показывается встроенный JPEG 160×120. Поворот HIF берётся из `irot`.
- Есть кнопка «Открыть во внешней программе». По бокам просмотра кнопки «назад» и «вперёд», на первой и последней плитке их нет.
- Видео: сначала играем исходник в WebView2. Если не играет — прокси, если прокси нет — кнопка «Открыть в системном плеере». «Не играет» — это ошибка или видео без картинки: если декодера нет, Chromium играет только звук. Видео отдаётся через asset-протокол Tauri, ему открыт только `M4ROOT`.
- Клавиатура: Enter открывает просмотр, ← / → листают, Пробел ставит или снимает галочку, Delete скрывает или возвращает, Esc закрывает. ← / → двигают курсор и в сетке. В просмотре листает и колесо мыши: вниз — вперёд, вверх — назад. Порядок — как на экране: → ведёт к следующей, то есть более старой плитке.
- Выделение как в Lightroom и Проводнике: щелчок выделяет плитку, Ctrl+щелчок добавляет или убирает её, Shift+щелчок и Shift+← / → выделяют диапазон, Ctrl+A — всё. Рамка (протянуть с зажатой левой кнопкой, хоть от плитки, хоть от пустого места) выделяет все плитки, которых касается, с Ctrl или Shift — добавляет их к выделению. Щелчок мимо плиток снимает выделение. Двойной щелчок открывает просмотр. Пробел и галочка на выделенной плитке ставят или снимают галочки у всего выделения; если в выделении есть и отмеченные, и неотмеченные, Пробел отмечает все.
- Перед открытием видео во внешней программе плеер в приложении ставится на паузу.

### Скрытие брака

- Брак (и фото, и видео) не удаляется, а скрывается из списка: файл на карте остаётся. Скрытая плитка не копируется, даже если у неё стояла галочка, и не входит в счётчик «Копировать», суммы и галочку дня.
- Скрывают Delete в сетке и в просмотре и кнопка в шапке — выделение или плитку под курсором. Это переключатель, как Пробел: если все цели уже скрыты, они возвращаются. Кнопка называется «Скрыть» или «Вернуть» по тому, что сделает. Подтверждения нет, после скрытия выделение сбрасывается. В просмотре после скрытия открывается следующая (более старая) нескрытая плитка, нет её — предыдущая, нет и её — просмотр закрывается.
- В сетке скрытых нет, день, где скрыто всё, исчезает. Если на картах есть скрытые, в шапке появляется галочка «Показывать скрытые (N)», при запуске она выключена. Тогда скрытые стоят на своих местах полупрозрачными, с пометкой «скрыто» и кнопкой «Вернуть» вместо галочки; их можно выделять (в том числе Shift и Ctrl+A) и вернуть Delete. Просмотр скрытые пропускает всегда.
- Список хранится в приложении: плитка (имя + время съёмки) и дата, когда её в последний раз видели на карте. Каждое чтение карт обновляет эту дату, записи, не виденные 30 дней (карту отформатировали), забываются при запуске. В настройках есть «Вернуть все скрытые (N)».
- Время клипа берётся из XML, а если вставлена только карта с прокси — из даты файла. Ключ тогда другой, и скрытый клип покажется снова.

### Уже скопированное

- При каждом запуске корень назначения обходится в фоне. Учитываются только медиафайлы, `.xmp` и `.acr` пропускаются. Индекс-файла нет.
- Совпадение определяется по имени, размеру и дате съёмки. Дата нужна, потому что номера `DSC…` после 9999 начинаются заново. Дату даёт диапазон в имени папки верхнего уровня; файл открывается (EXIF, XML клипа), только если день в диапазон не попал. Уже скопированное показывается серым и без галочки. Если отметить его вручную, оно копируется снова.
- Плитка считается скопированной, когда в библиотеке есть все её нужные файлы (см. настройку JPG/HIF в «Копировании»). Если скопирована часть, копируется остальное.

### Копирование

- Копируются отмеченные плитки, с прогрессом. С карты ничего не удаляется.
- Настройка «Копировать JPG/HIF вместе с RAW», по умолчанию выключена. Пока она выключена, у кадра с ARW нужен только ARW: его JPG и HIF не копируются. Кадр без ARW копируется целиком, у видео копируются все файлы. Если включить настройку позже, у уже скопированных кадров докопируются JPG и HIF. Просмотр, подпись плитки и суммы по дню показывают все файлы на карте.
- Два режима: одна папка на весь диапазон `ГГГГ.ММ.ДД - ГГГГ.ММ.ДД - описание` или папка на каждый день `ГГГГ.ММ.ДД - описание`. Внутри папки все файлы лежат вместе.
- Если день попадает в диапазон уже существующей папки библиотеки, эта папка предлагается по умолчанию, остальные дни идут в новую папку. Диапазон определяется по дате в начале имени; старые имена без « - » перед описанием тоже распознаются.
- Без описания новая папка называется просто датой или диапазоном. « - » для описания дописывается, когда поле получает фокус, если его не меняли руками, и срезается при потере фокуса. Первое поле открывается в фокусе. Смена режима сбрасывает ручные правки.
- Папку библиотеки можно сменить на одно это копирование, как в настройках: вписать или выбрать. В настройки она не сохраняется. При смене библиотека проверяется заново и план папок пересчитывается; пока идёт проверка, копировать нельзя. Серые «уже скопированные» плитки по-прежнему считаются по папке из настроек.
- Пока идёт копирование, окно не закрывается: отмены нет. После «Готово» показан полный путь каждой папки с кнопкой «Открыть в Проводнике».
- Файл сначала пишется как `*.part`, затем переименовывается, после чего сверяется размер. Дата файла сохраняется. Главное — скорость, поэтому файлы идут по одному и без fsync. Библиотека не перезаписывается: файл с тем же именем и размером пропускается, с другим размером — копирование останавливается с ошибкой.

### Прочее

- Корень назначения задаётся в окне «Настройки»: вписывается или выбирается стандартным диалогом выбора папки. Сохраняется. В шапке он показан серым (длинный обрезается, полный путь во всплывающей подсказке), рядом кнопка «Открыть в Проводнике». Если корень не задан, вместо пути кнопка «Выбрать папку…», она открывает настройки.
- Попапы (настройки, копирование) закрываются крестиком справа сверху или Esc. Щелчок мимо попапа его не закрывает.
- Иконки на кнопках — из шрифта Segoe Fluent Icons, он есть в Windows 11. Иконка приложения — карта памяти со стрелкой вниз, источник `src-tauri/icons/icon.svg`.
- Языки: русский и английский, по умолчанию — язык Windows, переключаются в настройках. Свои сообщения об ошибках Rust пишет на выбранном языке, системные приходят на языке Windows.
- Кнопка «Извлечь» безопасно извлекает USB-устройство каждой карты, как «Извлечь» в Проводнике. Поэтому уходят все диски камеры (с LUN = Multi это слот 1, слот 2 и PMHOME на одном USB-устройстве), а у картридера — все его слоты. Если диск занят другой программой, показывается ошибка. Сама после копирования камера не извлекается.
- Кнопки форматирования карты нет: форматировать только в камере. Sony не гарантирует работу карты, отформатированной на компьютере, а для CFexpress Type A способа сделать то же самое на компьютере нет.

## Разработка

```sh
mise install                # Rust и Node из mise.toml
npm install
npm run tauri dev           # запуск с горячей перезагрузкой
npm test                    # юнит-тесты Rust
npm run tauri build         # src-tauri\target\release\sony-transfer.exe
npm run tauri icon src-tauri/icons/icon.svg  # иконки из SVG; оставить только файлы из bundle.icon
                            # exe подхватит новые иконки, только если изменится tauri.conf.json (или после cargo clean)
```
